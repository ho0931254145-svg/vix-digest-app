每日強勢族群與 VIX 研究 — 手機 App（PWA）部署包

這個資料夾放到任何 HTTPS 靜態網站即可安裝成手機 App，例如：
- GitHub Pages：新建 repo → 上傳本資料夾所有檔案 → Settings → Pages → 選 main 分支 → 取得網址
- Cloudflare Pages：Create project → Direct Upload → 拖入本資料夾

手機安裝：
- iPhone：用 Safari 開網址 → 分享 → 加入主畫面
- Android：用 Chrome 開網址 → 選單 → 安裝應用程式

每日更新：只要替換 index.html，其餘檔案不用動。
App 開啟時會先抓最新版本；沒有網路時顯示上次看過的日報。
